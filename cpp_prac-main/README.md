# Практическое задание по C++: динамический массив

Практическое задание состоит из **пяти последовательных частей**. Каждая часть дорабатывает класс динамического массива из предыдущей.

## Состав задания

| Часть | Тема | Файл задания | Ветка GitHub |
|-------|------|--------------|--------------|
| 1 | Класс динамического массива | [part1_dynamic_array.md](part1_dynamic_array.md) | `part1-dynamic-array` |
| 2 | Исключения | [part2_exceptions.md](part2_exceptions.md) | `part2-exceptions` |
| 3 | Шаблоны | [part3_templates.md](part3_templates.md) | `part3-templates` |
| 4 | Операторы и перегрузки | [part4_operators.md](part4_operators.md) | `part4-operators` |
| 5 | Правило трёх/пяти | [part5_rule_of_five.md](part5_rule_of_five.md) | `part5-rule-of-five` |

## Порядок выполнения

1. Часть 1 — базовый класс `DynamicArray` для `int`.
2. Часть 2 — поверх кода части 1 добавляются проверки и выброс исключений.
3. Часть 3 — поверх кода части 2 класс переводится в шаблонный.
4. Часть 4 — перегрузка операторов (`[]`, `==`, `+=`, `-=`, итераторы).
5. Часть 5 — `operator=`, move-конструктор, move-оператор присваивания, проверка с AddressSanitizer.

Каждая следующая часть строится **на коде предыдущей**, поэтому сдавать нужно по порядку.

## Требования к сдаче (GitHub)

1. Создать репозиторий, основную ветку — `main`.
2. По каждой части создать **отдельную ветку** от актуального `main` (имена указаны в таблице выше).
3. В ветке — код класса и тестовая `main`-программа, демонстрирующая работу всех реализованных функций.
4. Запустить **Pull Request** со своей ветки в `main`, заполнить описание PR (какие задания выполнены).
5. Задание считается сданным после **merge ветки в `main`**.
6. Только после merge переходить к следующей части (ветка части N создаётся от `main`, куда уже мержен предыдущий код).

## Структура репозитория (рекомендуемая)

```
.
├── include/
│   └── DynamicArray.h      // объявление класса (часть 1, дорабатывается в частях 2–5)
├── src/
│   ├── DynamicArray.cpp    // реализация класса
│   └── main.cpp            // демонстрация/тесты
├── CMakeLists.txt          // или Makefile
└── README.md
```

## Компиляция

```bash
g++ -std=c++17 -Wall -Wextra src/*.cpp -o main
./main
```
