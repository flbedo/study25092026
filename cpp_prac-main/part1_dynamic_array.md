# Часть 1. Класс динамического массива

**Ветка GitHub:** `part1-dynamic-array` → merge в `main`

## Задание 1

Создать класс для работы с динамическим массивом типа `int`:

- хранить в свойствах указатель на данные и размер массива;
- реализовать функцию вывода всех значений массива;
- конструктор, получающий на вход размер массива;
- деструктор.

Реализовать:

- **сеттер**, проверяющий:
  - входной индекс на выход за границы массива;
  - входящее значение на принадлежность к промежутку **от −100 до 100 включительно**;
- **геттер**, проверяющий выход за границы массива.

## Задание 2

Реализовать **конструктор копирования**.

## Задание 3

Реализовать операцию **добавления значения в конец массива с расширением его размера**.
Добавляемое значение проверять на принадлежность к промежутку **−100…100**.

## Задание 4

Реализовать операцию **сложения и вычитания** для массивов (сложение/вычитание всех элементов):

```
arrA.add(arrB)  →  arrA = {arrA[0]+arrB[0], …, arrA[n]+arrB[n]}
```

- размер исходного массива **не изменяется**;
- если размеры массивов не совпадают, недостающие элементы считаются равными нулю.

## Сдача

1. Создать ветку `part1-dynamic-array` от `main`.
2. Вложить в репозиторий код класса и `main`-программу, демонстрирующую все 4 задания.
3. Открыть PR в `main` и дождаться **merge**.
