# Часть 2. Добавление исключений

**Ветка GitHub:** `part2-exceptions` → merge в `main`

Все задания **дополняют** класс динамического массива из части 1.

## Задание

Реализовать в классе следующие исключения. Выбрасывать **именно правильный тип**, а не общее `std::exception`:

| Ситуация | Тип исключения |
|----------|----------------|
| Ошибка выделения памяти (если используются функции C) | `std::bad_alloc` |
| Обращение к элементу по индексу вне границ массива | `std::out_of_range` |
| Попытка передать значение вне промежутка **−100…100** | `std::invalid_argument` |

### Пояснение по типам

- `std::bad_alloc` — выбрасывается, когда `new` / `malloc` не могут выделить память.
- `std::out_of_range` — индекс выхода за границы (в геттере, сеттере, `add`, `add`/`sub`).
- `std::invalid_argument` — значение вне допустимого диапазона.

См. справочник: <https://www.tutorialspoint.com/cplusplus/cpp_exceptions_handling.htm>

## Сдача

1. Создать ветку `part2-exceptions` от актуального `main` (после merge части 1).
2. Обернуть все проверки из части 1 выбросом подходящего типа исключения.
3. В `main`-программе продемонстрировать срабатывание каждого из трёх типов (`try` / `catch`).
4. Открыть PR в `main` и дождаться **merge**.
