# Часть 3. Добавление шаблонов

**Ветка GitHub:** `part3-templates` → merge в `main`

Все задания **дополняют** класс динамического массива из предыдущих частей.

## Задание 1

Реализовать **шаблонный класс** для массива элементов задаваемого типа.
Реализовать **отдельный сеттер с проверкой данных** для массивов, хранящих **целочисленные значения**.

Пример:

```cpp
if constexpr (std::is_integral_v<T>) {
    if (num > 100 || num < -100) /* … исключение … */;
}
```

Материалы:
- <https://ravesli.com/urok-177-yavnaya-spetsializatsiya-shablona-funktsii/>
- <https://stackoverflow.com/questions/14294267/class-template-for-numeric-types>
- <https://stackoverflow.com/questions/48433295/is-it-possible-to-overload-a-template-function-based-on-whether-the-type-is-an-i>

## Задание 2

Реализовать операцию вывода **`<<`**.

Материал: <https://metanit.com/cpp/tutorial/5.14.php>

## Задание 3

Реализовать операцию **нахождения расстояния между массивами** через расстояние между векторами (евклидова метрика):

```
dist = sqrt(Σ (a[i] − b[i])²)
```

- только для массивов с числами;
- для остальных типов данных возвращать ошибку **`std::bad_typeid`**;
- размер массивов должен быть одинаков, иначе возвращать **`std::invalid_argument`**.

## Сдача

1. Создать ветку `part3-templates` от актуального `main` (после merge части 2).
2. Вложить в репозиторий шаблонный класс с реализацией всех трёх заданий.
3. В `main`-программе продемонстрировать работу с двумя типами (числовым и нечисловым).
4. Открыть PR в `main` и дождаться **merge**.
