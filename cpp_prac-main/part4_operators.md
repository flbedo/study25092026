# Часть 4. Операторы и перегрузки

**Ветка GitHub:** `part4-operators` → merge в `main`

Все задания **дополняют** шаблонный класс динамического массива из части 3.

## Задание 1

Реализовать оператор обращения по индексу **`operator[]`**:

- с проверкой выхода за границы (как у геттера — выброс `std::out_of_range`);
- вернуть элемент по ссылке, чтобы запись `arr[i] = value` проходила через сеттер (с проверкой диапазона для целочисловых типов).

## Задание 2

Реализовать операторы сравнения:

- **`operator==`** — сравнение массивов по размеру и элементам;
- **`operator!=`** — как `!(a == b)` или отдельная реализация.

## Задание 3

Реализовать составные операторы арифметики:

- **`operator+=`** и **`operator-=`** — побайтовое сложение/вычитание (по логике из части 1, недостающие элементы — нули, размер не меняется);
- **`operator+=` / `operator-=` для скаляра** — прибавить/вычесть число ко всем элементам.

## Задание 4

Реализовать итераторы **`begin()`** и **`end()`**, чтобы класс работал в диапазоне:

```cpp
for (const auto& x : arr) {
    std::cout << x;
}
```

Для неконстантной версии также вернуть итераторы, позволяющие изменять элементы.

## Сдача

1. Создать ветку `part4-operators` от актуального `main` (после merge части 3).
2. Реализовать все операторы, сохранив проверки и исключения из предыдущих частей.
3. В `main`-программе продемонстрировать работу каждого оператора, включая цикл `for (auto& x : arr)`.
4. Открыть PR в `main` и дождаться **merge**.
